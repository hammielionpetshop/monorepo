### Added
- **Hitung Ulang SO Besar yang sudah disetujui.** Di detail laporan SO Besar (status Disetujui) kini ada tombol **Hitung Ulang** untuk membuat dokumen verifikasi tertaut ke SO induk ("Hitung Ulang dari SO-…", catatan wajib). Dokumen ini hanya memuat item yang berselisih di SO induk (opsional menampilkan item yang cocok), diisi qty fisik ke-2 langsung di Back Office lewat tabel input SO Besar yang sudah ada, lalu disetujui per item untuk mengoreksi stok.
  - Pembanding = **stok sistem terkini**, sehingga semua transaksi (jual, PO masuk, retur, transfer) sejak SO induk disetujui sudah otomatis diperhitungkan. Kolom **Mutasi sejak SO Induk** menampilkan pergerakan itu agar jelas kenapa stok sistem kini berbeda dari hitungan SO induk.
  - Nilai selisih dokumen hitung ulang **diperlakukan sebagai koreksi** dan **tidak dijumlahkan** sebagai kehilangan baru pada ringkasan & daftar laporan stock opname. Detail SO induk menautkan dokumen hitung ulangnya, dan sebaliknya.
