# Papan Klaim

Daftar pekerjaan yang sedang dikerjakan. Gunanya mencegah dua sesi mengerjakan
hal yang sama atau mengubah file yang sama.

## Cara pakai

1. Sebelum mulai, baca tabel di bawah. Kalau pekerjaan atau filenya sudah diklaim
   sesi lain, berhenti dan tanya pemilik.
2. Tambahkan satu baris untuk pekerjaan yang akan dimulai.
3. Setelah selesai dan digabung ke main, hapus barisnya.

Klaim ditulis di **main** lebih dulu, baru membuat branch. Klaim yang ditulis di
branch sendiri tidak terlihat sesi lain.

Perubahan database hanya boleh diklaim oleh **satu** pekerjaan dalam satu waktu.
Kalau kolom "Ubah database" sudah berisi "ya" di baris lain, tunggu sampai baris
itu selesai.
