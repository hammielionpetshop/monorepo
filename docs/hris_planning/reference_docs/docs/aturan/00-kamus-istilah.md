# Kamus Istilah

Satu istilah, satu arti. Kalau di sistem lama satu hal punya beberapa nama,
di sini dipilih satu nama dan nama lainnya dicatat di kolom "Nama lain".

Arti di bawah diambil dari sistem lama dan **belum dikonfirmasi pemilik**.
